# Сервис бронирования фильмов

**стек:** TypeScript, NestJS, PostgreSQL, TypeORM

- Проект реализован для того, чтобы разобраться в использовании фреймворка NestJS и взаимодействии с TypeORM.
- Также была проведена докеризация приложения с последующим разворачиванием на сервере.
- Для упрощения разворачивания были подготовлены Shell-скрипты
- Также подготовлен GitHub Workflow файл для автоматической докеризации приложения после пулл-реквеста, так контейнеры можно тащить прямо из гитхаба

## Установка

1. Скопировать на сервер:
  - файлы окружения,
  - папку public,
  - docker-compose
  - конфиги ngnix\
  - Для упрощения копирования в директории bin:
    - для копирования на сервер: `remote/copyToServer.sh`
2. развернуть контейнер с posgres
3. Заполнить БД данными
4. развернуть все остальные контейнеры: `docker compose up -d`
5. подключить сертификат. Вручную или выполнить скрипты в `/bin/`:
  - проверка получения сертификата: `dry-certificate.sh`
  - фактическое получение сертификата: `get-certificate.sh`
